# Project Context

SafeTap Engine is an AI-driven emergency intelligence engine for real-time risk classification and immediate safety guidance, designed for hotels and venues. It uses Google Gemini AI for emergency analysis, supports speech-to-text reporting, and provides safety-first guidance. The app is built with React, TypeScript, Vite, and Tailwind CSS.

## Main Features
- AI-driven emergency classification
- Speech-to-text reporting
- Safety-first guidance system

## Key Files
- App.tsx: Main UI and logic
- geminiService.ts: Handles AI emergency analysis
- types.ts: Type definitions for emergency analysis

## Usage
1. Install dependencies: `npm install`
2. Set `GEMINI_API_KEY` in `.env.local`
3. Run: `npm run dev`

## Technologies
- React 19
- TypeScript
- Vite
- Tailwind CSS
- Google Gemini AI
- Express (for backend, if needed)
